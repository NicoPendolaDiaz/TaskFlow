**TaskFlow** es una herramienta de gestión de tareas de alto rendimiento diseñada bajo los estándares de desarrollo de **Nico Péndola Díaz**. Combina una estética futurista "Neon-Glass" con una arquitectura robusta basada en Programación Orientada a Objetos (OOP).

## ✨ Características Principales

- 🌑 **Diseño Neon Glow**: Interfaz oscura de alto contraste con acentos en Cyan y Electric Blue.
- 🧊 **Glassmorphism**: Componentes con desenfoque de fondo y bordes traslúcidos.
- 🧱 **OOP Core**: Lógica de tareas encapsulada en clases reutilizables.
- 💾 **Persistencia Automática**: Los cambios se guardan localmente en tu navegador.
- 🌐 **Async Integration**: Conexión con APIs externas para sugerencias dinámicas.
- 📱 **Responsive Design**: Optimizado para cualquier tamaño de pantalla mediante Bootstrap 5.

## 🛠️ Instalación y Uso

1. Clonar el repositorio.
2. Abrir `index.html` en cualquier navegador moderno.
3. ¡Empieza a organizar tus flujos de trabajo!
